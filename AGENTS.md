# Agent instructions

The operating rules for this repo live in **`CLAUDE.md`**. Read that file, not
this one. It applies to every agent working here, Codex and Gemini included.

Then read `PLAN.md` (plan of record) and `NEXT-SESSION.md` (current state).

This file exists only because Codex looks for `AGENTS.md`. Keeping a second
copy of the rules here would guarantee the two drift apart, so it points
instead of duplicating.
