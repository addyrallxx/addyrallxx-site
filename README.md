# Portfolio

Adnan Shakib's personal site. A single scrolled Three.js world, chapters as
places rather than sections, tracing Dhaka to Calgary and the software built
along the way.

Next.js 16, React 19, TypeScript, Tailwind 4.

## Run it

```
npm install
npm run dev
```

Open http://localhost:3000.

`npm run build` builds for production. `npm run typecheck` runs `tsc --noEmit`.
`npm run lint` runs ESLint.
